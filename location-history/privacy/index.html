Where I Went

Privacy Policy

Updated November 25, 2026

Where I Went is a private timeline app for iPhone and Mac. It is designed to keep personal location history under the user's Apple account instead of a separate developer-operated account or server.

Data the app handles

Depending on the features a user enables, Where I Went may handle:

  • Precise location, timestamps, accuracy, and movement information.
  • Motion and fitness activity evidence used to improve capture decisions.
  • Place names, notes, corrections, favorites, private areas, and hidden periods created by the user.
  • Photos the user explicitly attaches to a trip or place.
  • Location-history files the user explicitly imports.

Where data is stored

The iPhone first stores retained observations in the app's protected local storage. It then synchronizes encrypted application fields through the user's private iCloud CloudKit database when iCloud is available.

The Mac app reads the same private iCloud library. Its default optimized mode uses a disposable local cache. A user may optionally keep a full local copy for offline use.

Where I Went does not require a separate account, email address, password, access code, or developer-operated backend.

Data collection and tracking

The developer does not receive or have access to the contents of a user's private CloudKit database through the app or CloudKit Console.

Where I Went:

  • Does not contain advertising or third-party analytics.
  • Does not track users across apps or websites.
  • Does not sell personal information.
  • Does not send location history to the developer or advertising partners.

Apple provides iCloud and may process data under Apple's privacy policy and the terms of the user's Apple account.

Permissions

  • Location: Used to record location history when the user enables recording. Background access supports continuous history capture.
  • Motion & Fitness: Optional. Used to improve activity recognition, capture detail, and battery decisions. Location recording still works if this permission is declined.
  • Photos: Used only when the user chooses to view or attach photos.

Permissions can be changed in Apple Settings at any time.

Retention and control

Retained source observations are intentionally preserved so the user's history can be rebuilt correctly. Privacy controls can hide periods or areas without destroying those source observations, and those choices can be reversed.

The app also provides a separate, destructive Delete All Location History command with two confirmations. It permanently removes the private iCloud library and local iPhone data; connected Macs remove their copies when they synchronize. Simply deleting the iPhone or Mac app does not delete the private iCloud library.

Users can export their visible history from within the app.

Security

Application-defined CloudKit fields are stored using CloudKit encrypted values. Local iPhone files use Apple data protection, and Mac files are kept in the app sandbox. This protection relies on Apple-managed services and is not a claim that Apple is technically unable to decrypt the data.

This website

The app never sends location history to this website. The site contains no analytics, advertising, cookies, forms, or application backend.

This site is hosted by GitHub Pages. GitHub states that it logs visitors' IP addresses for security purposes. That processing is governed by the GitHub General Privacy Statement.

Support requests opened through GitHub Issues are public. Users should never include precise locations, screenshots of their timeline, CloudKit identifiers, or other personal data in a public issue.

Children

Where I Went is not directed to children and does not knowingly collect personal information for the developer.

Changes

Material changes to this policy will be reflected by an updated effective date.

Contact

For help or privacy questions, visit the Where I Went support page. Support requests on GitHub are public. Do not include your location history or other personal details.
